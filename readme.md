# vps-init-shield

Комплексный скрипт для автоматической инициализации и защиты VPS на базе Debian и Ubuntu.

## Поддерживаемые ОС
- **Debian 11+**
- **Ubuntu 20.04+** (включая 22.04 и 24.04)

## Возможности
- **Оптимизация ядра**: Включение BBR, настройка сетевых стеков и системных лимитов.
- **Безопасность**:
  - Перенос SSH на порт `2244`.
  - Настройка UFW (Firewall): открыты только необходимые порты (2244, 80, 443, 53, 51820 и др.).
  - Базовая защита через Fail2Ban.
- **Сервисы**:
  - **3x-ui**: Универсальная панель управления прокси (XRay).
  - **AmneziaWG**: Современный VPN протокол с продвинутой обфускацией.
  - **AdGuardHome**: Персональный DNS сервер с фильтрацией рекламы и трекеров.

## Установка

`ash
# Сделайте скрипт исполняемым
chmod +x setup.sh

# Запустите установку под root
sudo ./setup.sh
`

## Важные примечания
После завершения работы скрипта:
1. Сохраните выведенные данные (пароли и пути).
2. Выполните **reboot** для активации параметров ядра и модуля AmneziaWG.
