# vps-vpn-triad

**Комплексный VPN-бандл (3x-awg-adg)** для автоматической инициализации и защиты VPS. 
Объединяет три мощных инструмента для обхода блокировок, приватности и фильтрации трафика.

## Состав бандла
- **3x-ui**: Панель управления Xray для гибкой настройки прокси.
- **AmneziaWG**: VPN с продвинутой обфускацией против глубокого анализа трафика (DPI).
- **AdGuardHome**: Персональный DNS-фильтр для блокировки рекламы и защиты приватности.

## Поддерживаемые ОС
- **Debian 11+**
- **Ubuntu 20.04+**

## Установка

`ash
# Сделайте скрипт исполняемым
chmod +x setup.sh

# Запустите установку под root
sudo ./setup.sh
`
