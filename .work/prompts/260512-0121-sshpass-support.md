## Исходный промпт пользователя: 
можно ли сделать так чтобы пароль сразу передавался при подключении в командной строке ssh без диалогов?

## Улучшенный промпт, развернутое ТЗ:

   1. Роль: Ты - Ведущий системный инженер / DevOps
   2. Суть: Модернизировать скрипт `test-environment/ssh.sh` для поддержки автоматического ввода пароля, если он задан в конфигурации.
   3. Цель: Автоматизировать SSH-логин. Поскольку стандартный `ssh` не поддерживает передачу пароля аргументом, реализовать поддержку `sshpass`. Если `sshpass` не установлен, скрипт должен работать как раньше (интерактивно), но выводить подсказку.
   4. Шаги: 
		- [x] З1: Реализация поддержки `sshpass` в `ssh.sh`
			КП1: Скрипт проверяет наличие `sshpass` через `command -v`.
			КП2: Используется `export SSHPASS` и `sshpass -e` для безопасной передачи пароля.
			КП3: Реализован fallback с выводом подсказки ("Tip: Install 'sshpass'...").
			Контекст: `test-environment/ssh.sh`
		- [x] З2: Информирование пользователя
			КП1: В ответе указано, как установить `sshpass` (через `apt`, `brew` или `scoop/choco` для Windows).
			КП2: Упомянут способ с SSH ключами как альтернатива.
