## 1. Роль

Ты - senior infrastructure automation engineer и maintainer bash-инсталлятора для малых VPS с 512MB RAM и 8GB HDD. Ты хорошо знаешь `bash`, `iptables`, `UFW`, `systemd`, TDD для shell-скриптов, идемпотентные installer-flow и ограничения проекта `3x-awg-adg-bundle`.

## 2. Суть

Нужно заменить жесткую модель `target|relay` на единый интерактивный сценарий: каждый сервер настраивает локальный direct-стек `AmneziaWG + 3x-ui + AdGuardHome`, а затем оператор сам решает, делать ли с этого сервера L4-проброс портов на один или несколько целевых IP. Проброс должен быть универсальным, не ограниченным AWG и Reality.

Также нужно исправить публичный доступ к DNS endpoint AdGuardHome: если скрипт выводит `DNS endpoint: SERVER_IP:ADG_DNS_PORT`, firewall не должен блокировать этот порт снаружи.

## 4. Контекст

- [ ] `src/setup` - источник истины для логики установки, конфигов и регрессий.
- [ ] `setup.sh` - собранный артефакт; не править его вручную как основной источник изменений.
- [ ] 3x-ui должен настраиваться вручную через официальный interactive installer.
- [ ] Скрипт не создает Reality inbound автоматически и не выпускает клиентские ссылки автоматически.
- [ ] Проверка `3x-ui` не является критичной частью базовой валидации.
- [ ] Публичный доступ к AdGuardHome Web UI по случайному web-порту - ожидаемое поведение.
- [ ] Публичный DNS endpoint AdGuardHome на случайном порту является частью public data-plane, если выводится пользователю.
- [ ] Публичный доступ к 3x-ui panel и Reality - ожидаемое поведение после ручной настройки оператором и открытия нужных портов.
- [ ] Порт `443/tcp` зарезервирован под Reality.
- [ ] Разница между `Интернет РФ` и `Глобальный интернет` на диаграмме логическая: до DPI и после DPI. Специальная маршрутизация для этих зон не нужна.
- [ ] Target-сервер устанавливается тем же скриптом; если проброс портов с него дальше не нужен, оператор отвечает `no` на вопрос о forwarding.
- [ ] Relay-сервер устанавливается тем же скриптом; оператор отвечает `yes` на вопрос о forwarding и интерактивно добавляет целевые серверы и порты.
- [ ] Скрипт должен оставаться пригодным для VPS с 512MB RAM и 8GB HDD.
- [ ] Повторный запуск должен быть безопасным и не должен плодить firewall/NAT-дубли.
- [ ] SSH использует порт `2244`, Fail2Ban включен.
