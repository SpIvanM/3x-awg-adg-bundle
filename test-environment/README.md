# Тестовые Среды (Debugging Environments)

Данная директория предназначена для управления доступом к серверам, на которых производится отладка и тестирование инсталлятора.

## Структура
- `.env-example/` — Публичные шаблоны конфигураций.
- `.env/` — (**Скрыто**) Реальные учетные данные серверов. Игнорируется Git и AI-агентами.

## Как настроить новую среду
1. Создайте папку для вашего сервера в `test-environment/.env/`:
   ```bash
   ./test-environment/init_server.sh my-server
   ```
2. Заполните файлы `ip`, `port`, `user` и `key` (или `password`) в созданной директории.
   - В качестве образца используйте файлы из `.env-example/server-template/`.

## Подключение
Используйте скрипт-обертку из корня проекта:
```bash
./test-environment/ssh.sh my-server
```

## Безопасность
Все данные в `test-environment/.env/` являются приватными. Никогда не удаляйте эту папку из `.gitignore`.
Агенты ИИ проинструктированы не читать содержимое этой папки.
